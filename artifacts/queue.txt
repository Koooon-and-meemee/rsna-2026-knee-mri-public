# 24. Added 25 Aug 13:45. The architecture question, and it turned out to be one
# line rather than a new model.
#
# SliceNet feeds every slice into the backbone as `s.expand(-1, 3, -1, -1)` -
# the same grayscale image replicated across all three input channels. Two of
# the three carry no information, and they have carried none since the first run
# in this project.
#
# 2.5D fills them with (i-1, i, i+1). Identical tensor shape, identical FLOPs,
# identical pretrained stem - and the ImageNet stem is built for correlated
# channels, which adjacent MRI slices are. Free at training and at inference,
# which also means it does not cost anything on the efficiency track.
#
# It predicts its own reason for existing: depth 48 bought nothing because more
# slices cannot help a model that processes each slice alone. This is the first
# path to through-plane information the architecture has ever had.
#
# m31's recipe exactly, one flag changed, 12 epochs. Judged on peak pv-hold
# against tiny's 0.8835 - and against the 0.882-0.887 band that thirteen models
# across seven recipes have failed to leave.

# 25. Added 25 Aug 13:50, from the operator's observation: the current structure
# is attention POOLING, not self-attention.
#
# AttentionPool scores each slice and takes a weighted sum. The slices never see
# each other. It can answer "how much does this slice matter" and cannot answer
# "does this slice matter GIVEN what the next one shows" - which is how a stack
# is actually read, a signal confirmed by its neighbours or dismissed as an
# artefact.
#
# A transformer encoder over the D=32 slice features fixes that. ~9.5M
# parameters against a backbone that runs 32 times per series over 224x224
# images, so the compute is negligible and the efficiency track is unaffected.
#
# Deliberately run SEPARATELY from m53nbr rather than together. They attack the
# same gap from different ends - 2.5D gives local through-plane context inside
# the backbone, this gives global slice interaction after it - and if the pair
# were run as one config a gain could not be attributed. Combine only if one of
# them works.
